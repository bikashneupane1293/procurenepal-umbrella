# ProcureNepal

Construction Industry Operating System for Nepal.

**Stack:** Angular 22 · NestJS 11 · PostgreSQL 18 · Redis · Python FastAPI · Ollama · Prisma · Docker (OrbStack)

## Structure
- `api/` — NestJS backend
- `web/` — Angular frontend
- `python-engine/` — FastAPI calc service
- `infrastructure/` — Docker, nginx
- `docs/` — Documentation
